# برومبت التصدير من برنامج الخازن

الخازن هو مصدر كشوفات الوكلاء بالبركة (`company.md` §1). البرومبت أدناه (قراءة فقط، ومفروضة تقنياً) يشغّله المستخدم على **الجهاز اللي عليه الخازن أو قاعدة بياناته**، عن طريق Claude Cowork أو Claude Code على ويندوز. Desktop Commander بالكلاود ما يوصل لهذا الجهاز.

بنية قاعدة بيانات الخازن (نوع المحرك، وأسماء الجداول) **غير موثقة عندنا**، لذلك البرومبت يبدأ باكتشاف البنية وتوثيقها، ويرجع لتصدير التقارير من واجهة البرنامج إذا تعذر الوصول المباشر.

**عند استلام المجلد:**
1. اقرأ `00_فهرس.md` و`02_خريطة_الجداول.md` أولاً.
2. طابق المجاميع المحسوبة من القاعدة مع مجاميع تقارير البرنامج نفسه. أي فرق يوقف التحليل لحد ما يتفسر.
3. سجّل نوع القاعدة وخريطة الجداول بـ `company.md` حتى ما نكتشفها كل مرة.
4. بعد أول تشغيل، المرحلة 3 بالبرومبت تحوّل الاستعلامات إلى تشغيل صامت بـ `scripts/khazen_export.ps1`، ويصير التحديث بأمر واحد أو بجدولة.

دالة القراءة الآمنة لـ SQL Server (PowerShell، بدون أي تنصيب):

function Invoke-ReadOnlyQuery([string]$ConnStr, [string]$Sql, [string]$OutCsv) {
    $q = $Sql.Trim()
    if ($q -notmatch '^(?i)(SELECT|WITH)\b') { throw "مرفوض: الاستعلام لازم يبدأ بـ SELECT أو WITH" }
    $deny = '(?i)\b(INSERT|UPDATE|DELETE|MERGE|TRUNCATE|DROP|ALTER|CREATE|INTO|EXEC|EXECUTE|GRANT|REVOKE|DENY|BACKUP|RESTORE|DBCC|OPENROWSET|OPENQUERY|SHUTDOWN|KILL)\b|\bxp_|\bsp_|#'
    if ($q -match $deny) { throw "مرفوض: كلمة كتابة أو تنفيذ بالاستعلام: $($Matches[0])" }
    $cn = New-Object System.Data.SqlClient.SqlConnection $ConnStr
    $cn.Open()
    $tx = $cn.BeginTransaction()
    try {
        $cmd = $cn.CreateCommand(); $cmd.Transaction = $tx; $cmd.CommandText = $q; $cmd.CommandTimeout = 600
        $dt = New-Object System.Data.DataTable
        $dt.Load($cmd.ExecuteReader())
        $dt | Select-Object * -ExcludeProperty RowError, RowState, Table, ItemArray, HasErrors |
            Export-Csv -Path $OutCsv -NoTypeInformation -Encoding UTF8
        return $dt.Rows.Count
    } finally { $tx.Rollback(); $cn.Close() }
}
# مثال اتصال بحساب ويندوز: "Server=.\SQLEXPRESS;Database=<اسم القاعدة>;Integrated Security=True;ApplicationIntent=ReadOnly"
# بـ PowerShell 7 استخدم -Encoding utf8BOM بدل UTF8 حتى يظهر العربي صحيح.
