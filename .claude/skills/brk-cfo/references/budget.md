# الموازنة التقديرية السنوية (2027)

موازنة على المحركات (حجم، سعر، صرف، تضخم، رواتب) بمعادلات حية، وقائمة دخل شهرية، وتدفق نقدي شهري، وسيناريوهات. الأداة `scripts/build_budget.py`. الإطار العام بـ `treasury-fpa.md` §4–5، والأرقام الكلية بـ `iraq-market.md`.

## المحتويات
1. المراحل والتقويم
2. أرقام سنة الأساس
3. المحركات والقرارات
4. البناء
5. الفحص قبل التسليم
6. المتابعة الشهرية

## 2. أرقام سنة الأساس

**المبدأ:** ابدأ من الفعلي المطابق، مو من التقديرات. وكل رقم يحمل مصدره بعمود المصدر.

| البند | المصدر الأفضل | ملاحظات |
|---|---|---|
| المبيعات الإجمالية | فواتير البيع بالخازن (16)، صافية من المرتجعات | قبل خصم 14%، لأن الأداة تحسب الخصم. 2026: 34.63 مليار لكانون الثاني إلى أيلول، فأشهر الأساس = 9 |
| المواد | فواتير الشراء (18) أو قيود الاستهلاك | **مو** كلفة المبيعات بالخازن، لأن قائمة الدخل المرحلية بيها خسارة 12.3 مليار بسبب غياب تسوية مخزون آخر المدة (`company.md` §5). المشتريات تقريب للاستهلاك، ويُذكر هذا |
| الرواتب | 3111 و3112 و3116 والضمان 3151 و336300005، أو Odoo من آب | حوالي 260 مليون شهرياً. الضمان 12% حصة الشركة (`iraq-law.md` §5) |
| الطاقة والصيانة والإدارية | ميزان المراجعة بالخازن، حسابات المجموعة 3 | صنّف كل حساب لمجموعة ومحرك |
| الاندثار | سجل الأصول | ثابت + إضافات الاستثمار |
| التمويل | الفوائد والعمولات | يدوي إذا بيه قروض جديدة |

**نسبة الدولار لكل بند:**
- **المواد المستوردة:** 1، وبعضها خليط إذا انشرى محلياً.
- **الصيانة:** جزئية (أدوات احتياطية مستوردة).
- **الرواتب والإيجار:** صفر.

**سعر صرف الأساس** هو السعر اللي انحسبت بيه أرقام الأساس: 1,450 بالخازن، و1,540 بـ Odoo.

**ملف الأساس:** `base.csv` بأعمدة البند، والمجموعة، والمحرك، والمبلغ، وأشهر الأساس، ونسبة الدولار، والمصدر. العينة بـ `assets/sample_budget_base.csv`.

## 3. المحركات والقرارات

| المحرك | يستخدم لـ | المعامل |
|---|---|---|
| مبيعات | المبيعات الإجمالية | (1 + الحجم) × (1 + السعر) |
| حجم | المواد، والطاقة، والتغليف | (1 + الحجم) × خليط الصرف والتضخم |
| تضخم | الصيانة، والإدارية، والخدمات | خليط الصرف والتضخم |
| رواتب | الرواتب والضمان | (1 + الزيادة) × (1 + تغير العدد) |
| ثابت | الإيجار، والاندثار الحالي | 1 |
| نسبة من المبيعات | النقل، والعمولات | مثل المبيعات |
| يدوي | الفوائد، والبنود الاستثنائية | تنكتب أشهره بالملف |

**القرارات اللي تطلب من الإدارة** (كلها خلايا يدوية):
- نمو الحجم.
- زيادة الأسعار. الأفضل تجي من التسعيرة الجديدة (`pricing-review.md`).
- زيادة الرواتب وتغير العدد.
- الاستثمارات الرأسمالية.
- سحوبات الشركاء.
- نسبة الدولار من السوق.

**الافتراضات الكلية:**
- **الصرف:** الرسمي 1,520، والسوق بتاريخه.
- **التضخم:** صندوق النقد 3% لسنة 2027، مع سيناريو الضعف. للمواد، الأفضل اتجاه أسعار الشراء الفعلي (`price_refs.py`).
- **الموسمية:** من مبيعات الخازن الشهرية (`--khazen`).

## 4. البناء

```bash
python scripts/build_budget.py --base base.csv --fx-base 1450 \
    --fx-market <السوق> --fx-market-basis "<المصدر والتاريخ>" --market-share <النسبة> \
    --volume-growth <الحجم> --price-increase <السعر> --wage-increase <الرواتب> \
    --opening-cash <النقد الافتتاحي> --opening-receivables <ذمم الوكلاء> --opening-payables <ذمم الموردين> \
    --khazen "<مجلد الخازن>" --out "الموازنة_التقديرية_2027.xlsx" --check --pdf
```

**الأوراق:**
1. **الافتراضات:** الصرف والنمو والكلف والنقد والموسمية، كلها يدوية.
2. **الملخص:** صافي المبيعات، والربح التشغيلي، وصافي الربح، مقابل الأساس. وأدنى رصيد نقدي وشهره، وحساسية الصرف.
3. **بنود الموازنة:** كل بند بأساسه ومعامله وموازنته وتوزيعه الشهري، والجزء الدولاري.
4. **قائمة الدخل الشهرية:** بالملايين، مع الأساس والتغير.
5. **التدفق النقدي:** المقبوضات بعد تأخير التحصيل، والمدفوعات بعد تأخير الدفع. الاستثمارات والسحوبات والضريبة والأقساط إدخال يدوي شهري.
6. **السيناريوهات:**
   - انخفاض الحجم.
   - بدون زيادة أسعار.
   - الدولار كله من السوق.
   - دولار أعلى.
   - تضخم مضاعف.
   - الأسوأ مجتمعاً.

   كلها خلايا تنعدل، وبيها فحص يطابق الأساس ويه قائمة الدخل.
7. **المنهجية والاعتماد.**

## 5. الفحص قبل التسليم

- `--check` بدون أخطاء معادلات، وخلية فحص السيناريوهات = صفر.
- **الأساس:** مجموع بنود الأساس يطابق مصادرها (المبيعات مع الخازن، والرواتب مع كشوفها).
- **منطق النتيجة:** إذا الربح الأساسي سالب أو أدنى رصيد نقدي سالب، فهذي هي **الخلاصة الأولى بالرد**، ويرافقها شنو يصلحها (سعر، أو حجم، أو تأجيل استثمار، أو تمويل).
- **"غير متوفر" ليس صفراً:** أي بند ناقص يُذكر بالملخص والرد، مو يُترك صفراً بصمت.

## 6. المتابعة الشهرية

بعد الاعتماد، الفعلي مقابل الموازنة شهرياً بـ `build_cost_workbook.py --budget` (للكلف). كل انحراف أكبر من 5% يحتاج تفسيراً: سعر، أو حجم، أو صرف، أو توقيت. ولو تغيّر الصرف أو التضخم بشكل جوهري، حدّث الافتراضات وطلّع توقعاً محدثاً (rolling forecast) بدل ما تنتظر نهاية السنة.
