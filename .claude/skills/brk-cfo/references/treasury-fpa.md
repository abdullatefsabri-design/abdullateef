## 1. التدفق النقدي لـ 13 أسبوعاً

أهم أداة بيد المدير المالي ببيئة مثل العراق: صرف متقلب، ودفعات حكومية تتأخر، وموازنة اتحادية تتأخر.

**الهيكل (الطريقة المباشرة، أسبوعياً):**
```
الرصيد الافتتاحي
+ المقبوضات: حسب الزبون الرئيسي (أكبر 10) + الباقي مجمّع
− المدفوعات: الرواتب، الضمان والضريبة، الموردون (حسب تواريخ الاستحقاق)، الإيجار،
             الأقساط والفوائد، الإنفاق الرأسمالي، تحويلات الدولار
= الرصيد الختامي
  مقابل الحد الأدنى للسيولة (مثلاً رواتب شهر ونصف + أقساط الشهر)
  → الفجوة أو الفائض
```
**قواعد:**
- المقبوضات على **تاريخ التحصيل الفعلي حسب تاريخ كل زبون**، مو شروط الفاتورة.
- كل أسبوع: الفعلي مقابل المتوقع، وكل فرق كبير يُفسر. دقة التوقع مؤشر أداء للمالية نفسها.
- الأسبوع 13 ينطي إنذاراً مبكراً، والإنذار المبكر هو الفرق بين التفاوض والطوارئ.
- افصل الدينار عن الدولار بجدولين. سيولة بالدينار ما تسدد التزاماً بالدولار بدون كلفة صرف ومخاطرة.

## 2. رأس المال العامل

```
أيام التحصيل DSO = الذمم المدينة ÷ الإيرادات × عدد أيام الفترة
أيام المخزون DIO = المخزون ÷ كلفة المبيعات × عدد الأيام
أيام السداد  DPO = الذمم الدائنة ÷ كلفة المبيعات (أو المشتريات) × عدد الأيام
دورة النقد  CCC = DSO + DIO − DPO
```
كل يوم بدورة النقد يساوي (الإيرادات اليومية) محبوسة بالنقد. **مثال:** إيراد سنوي 36 مليار، يعني حوالي 100 مليون باليوم، فتخفيض الدورة 10 أيام يحرر مليار دينار بدون قرض.

**الروافع:** خصم تعجيل للدفع النقدي، وفوترة فورية عند الإنجاز، ومتابعة أسبوعية للمتأخرات، وتصفية المخزون البطيء، وتفاوض على مدد السداد مع الموردين (بدون الإضرار بالعلاقة أو خسارة خصم أكبر من كلفة التمويل).

## 3. النسب المالية

| المجموعة | النسبة | المعادلة | تقرأ منها |
|---|---|---|---|
| السيولة | التداول | الموجودات المتداولة ÷ المطلوبات المتداولة | القدرة على السداد قصير الأجل |
| | السريعة | (المتداولة − المخزون) ÷ المطلوبات المتداولة | بدون الاعتماد على بيع المخزون |
| | النقدية | (النقد + ما يعادله) ÷ المطلوبات المتداولة | أقسى اختبار |
| الربحية | هامش مجمل الربح | مجمل الربح ÷ الإيرادات | التسعير وكلفة البضاعة |
| | هامش EBITDA | EBITDA ÷ الإيرادات | الربحية التشغيلية قبل التمويل والاندثار |
| | هامش صافي الربح | صافي الربح ÷ الإيرادات | |
| | العائد على حقوق الملكية ROE | صافي الربح ÷ متوسط حقوق الملكية | |
| | العائد على رأس المال المستخدم ROCE | EBIT ÷ (إجمالي الأصول − المطلوبات المتداولة) | كفاءة استخدام كل رأس المال |
| المديونية | الدين إلى حقوق الملكية | إجمالي الديون ÷ حقوق الملكية | |
| | صافي الدين إلى EBITDA | (الديون − النقد) ÷ EBITDA | سنوات السداد التقريبية. البنوك تراقبه |
| | تغطية الفوائد | EBIT ÷ مصروف الفوائد | |
| الكفاءة | دوران الأصول | الإيرادات ÷ متوسط الأصول | |

**تحليل دوبونت:** ROE = هامش صافي الربح × دوران الأصول × (الأصول ÷ حقوق الملكية). يبين إذا العائد جاي من الربحية أو الكفاءة أو الاقتراض.

**قاعدة القراءة:** النسبة وحدها ما تحچي. قارنها بالشركة نفسها عبر الزمن، وبالموازنة، وبالقطاع. واسأل دائماً شنو اللي غيّر البسط وشنو اللي غيّر المقام.

## 4. الموازنات

| الأسلوب | متى |
|---|---|
| تزايدي (السنة السابقة + نسبة) | سريع، لكنه يورّث الهدر |
| من الصفر (ZBB) | لإعادة هيكلة الكلف أو بالأزمات. كل بند يبرر نفسه |
| على المحركات (Driver-based) | الأدق: الإيراد = حجم × سعر، والكلف المتغيرة = معدل × حجم |
| متجددة (Rolling) | 12 إلى 18 شهراً تُحدث فصلياً. مناسبة للبيئات المتقلبة |

**التقويم:** الافتراضات الكلية (صرف، تضخم، أسعار) ← الإيرادات ← الكلف حسب الأقسام ← الرأسمالي ← النقد ← المراجعة والاعتماد ← التوزيع الشهري.

**بالعراق تحديداً:**
- افتراض سعر الصرف وثّقه صراحة: الرسمي من 2026-10-07 هو 1,520، والسوق الموازي أعلى.
- إذا زبائنك حكوميون، تأخر إقرار الموازنة الاتحادية يأخر التزاماتهم. ابنِ سيناريو لتأخير 3 إلى 6 أشهر.
- الإيرادات العامة تعتمد بشدة على النفط، فاعتبر سعر النفط محركاً غير مباشر لطلب السوق المحلي ولقدرة الدولة على الدفع.

## 6. تقييم الاستثمار

```
صافي القيمة الحالية NPV = Σ [التدفق النقدي للسنة t ÷ (1 + r)^t] − الاستثمار الأولي
معدل العائد الداخلي IRR = المعدل اللي يخلي NPV = 0
فترة الاسترداد          = السنوات لحد ما التدفقات المتراكمة تغطي الاستثمار
مؤشر الربحية PI          = القيمة الحالية للتدفقات ÷ الاستثمار
```
**القواعد:**
- استخدم **التدفق النقدي** وليس الربح، والإضافي فقط (مع المشروع ناقص بدونه)، وبعد الضريبة، ومتضمناً رأس المال العامل المطلوب واسترداده بالنهاية.
- **الثبات:** تدفقات اسمية بالدينار مع معدل خصم اسمي بالدينار (يتضمن التضخم ومخاطر الصرف)، أو تدفقات بالدولار مع معدل بالدولار. الخلط بينهما يقلب القرار.
- معدل الخصم هو كلفة رأس المال المرجحة (WACC) زائد علاوة مخاطر المشروع. بالعراق علاوة المخاطر للبلد والسيولة معتبرة، فلا تستخدم معدلات أسواق مستقرة.
- **NPV هو المعيار الحاكم** عند التعارض مع IRR (المشاريع المتنافية أو التدفقات غير التقليدية).
- فترة الاسترداد مهمة بالعراق كمقياس للمخاطرة. مشروع يسترد بعد 7 سنوات ببيئة متقلبة يحتاج NPV عالياً جداً حتى يُقنع.

**شراء أو استئجار:** قارن القيمة الحالية لكلفة الامتلاك (الشراء + الصيانة − القيمة المتبقية − الوفر الضريبي من الاندثار) مع القيمة الحالية لدفعات الإيجار (بعد الضريبة)، بمعدل كلفة الاقتراض بعد الضريبة.

## 7. إدارة مخاطر الصرف (الدينار والدولار)

**أنواع التعرض:**
- **المعاملات:** فاتورة دولار مستحقة الدفع.
- **الترجمة:** أرصدة دولارية تُعاد بنهاية الفترة.
- **الاقتصادي:** قدرتك على البيع بسعر يغطي كلفتك الدولارية.

**صافي المركز = الأصول النقدية بالدولار − الالتزامات النقدية بالدولار (+ المشتريات الدولارية الملتزم بها)**

**الأدوات المتاحة بالعراق** (سوق المشتقات للتحوط محدود جداً):
1. **التحوط الطبيعي:** طابق عملة الإيراد مع عملة الكلفة. إذا تشتري بالدولار، سعّر بالدولار أو بالدينار مع بند ربط بسعر الصرف.
2. **بنود العقود:** تعديل السعر إذا تغيّر الصرف أكثر من نسبة محددة، ومدة صلاحية قصيرة لعروض الأسعار.
3. **توقيت السداد:** سدد الالتزامات الدولارية مبكراً إذا تتوقع ارتفاع الدولار، وحوّل المقبوضات الدولارية حسب الحاجة الفعلية.
4. **الاحتفاظ بنقد دولاري** يغطي الالتزامات الدولارية المؤكدة للأشهر القادمة.
5. **إعادة التفاوض** مع الموردين على عملة الفوترة أو المشاركة بالأثر.

**مثال من قرار 2026-10-07:** ذمة دائنة 100,000$ مسجلة على 1,320 وصارت على 1,520 تعني خسارة 100,000 × 200 = **20,000,000 دينار**. احسب مركزك الكامل بـ:
```
python scripts/fx_impact.py balances.csv --new 1520 --old 1320
```
