## 1. COSO 2013 بلغة عملية

| المكوّن | السؤال اللي يسأله المدير المالي |
|---|---|
| بيئة الرقابة | هل الإدارة العليا تلتزم بالقواعد قبل غيرها؟ هل توجد مدونة سلوك وهيكل صلاحيات مكتوب؟ |
| تقييم المخاطر | شنو أكبر 10 مخاطر مالية عندنا (صرف، سيولة، احتيال، ضريبة، تركّز زبائن)؟ ومنو مسؤول عن كل وحدة؟ |
| أنشطة الرقابة | موافقات، فصل مهام، مطابقات، صلاحيات أنظمة، جرد |
| المعلومات والتواصل | هل الأرقام توصل للشخص الصحيح بالوقت الصحيح؟ هل يوجد خط إبلاغ عن المخالفات؟ |
| المتابعة | منو يراجع أن الضوابط تشتغل فعلاً؟ التدقيق الداخلي، أو مراجعة دورية من المدير المالي |

**القاعدة الذهبية:** شخص واحد ما يكدر يبدأ المعاملة ويوافق عليها ويسجلها ويدفعها ويطابقها. أي اثنين من هذي بيد شخص واحد يعني ثغرة.

## 2. دورة الشراء والدفع وفصل المهام (مع Odoo)

| الخطوة | المسؤول | الضابط | بـ Odoo |
|---|---|---|---|
| 1. طلب الشراء | القسم الطالب | مبرر، ومركز كلفة، وموازنة متاحة | طلب موافقة `approval.request` مع أسطر منتجات |
| 2. الموافقة | المدير حسب مصفوفة الصلاحيات | حسب المبلغ، والطالب ما يوافق على طلبه | قواعد الموافقين بنوع طلب الموافقة |
| 3. طلب عروض الأسعار | المشتريات | 3 عروض فأكثر فوق حد معيّن، ومقارنة موثقة | طلب عرض سعر (RFQ) مسودة. الإجراء `server_actions/approval_request_create_rfq.py` بهذا المستودع ينشئه من طلب الموافقة |
| 4. أمر الشراء | المشتريات، وموافقة إضافية فوق الحد | المورد مسجل ومعتمد، والسعر مطابق للعرض الفائز | تأكيد أمر الشراء مع موافقة ثنائية (Purchase → Settings → Order Approval) |
| 5. الاستلام | المخزن (مو المشتريات) | فحص الكمية والجودة، ومذكرة استلام | إيصال الاستلام `stock.picking` |
| 6. الفاتورة | الحسابات | **مطابقة ثلاثية:** أمر الشراء = الاستلام = الفاتورة | سياسة الفوترة "على الكميات المستلمة" (Bill Control: Received quantities) |
| 7. الدفع | الخزينة، بتوقيعين | الدفع فقط لفاتورة مطابقة ومعتمدة، ولحساب المورد المسجل | دفعة المورد. تغيير حساب المورد المصرفي يحتاج موافقة منفصلة |
| 8. المطابقة المصرفية | محاسب غير من يدفع | شهرياً خلال 5 أيام عمل | مطابقة كشف المصرف |

**ملاحظة على الإجراء الموجود بالمستودع:** يبحث عن المشتري بالاسم (`BUYER_NAME`)، والتعليق بالكود نفسه يقول إن الأفضل البحث بالـ login أو بمعرف ثابت. الاسم قد يتكرر أو يتغير، فتنسند أوامر الشراء لشخص خطأ بدون ما ينتبه أحد.

## 3. مصفوفة الصلاحيات المالية (DOA)

نموذج للبداية. الحدود بالدينار وتُعدَّل حسب حجم الشركة، وتعتمدها الإدارة أو مجلس الإدارة كتابياً.

| العملية | حتى 5 مليون | حتى 25 مليون | حتى 100 مليون | أكثر |
|---|---|---|---|---|
| طلب شراء تشغيلي | مدير القسم | المدير المالي | المدير العام | مجلس الإدارة |
| إنفاق رأسمالي (خارج الموازنة) | المدير المالي | المدير العام | المدير العام | مجلس الإدارة |
| إنفاق رأسمالي (ضمن الموازنة المعتمدة) | مدير القسم | المدير المالي | المدير العام | المدير العام + إبلاغ المجلس |
| توقيع الدفع (توقيعان دائماً) | محاسب أول + المدير المالي | المدير المالي + المدير العام | المدير المالي + المدير العام | + عضو مجلس |
| شطب دين أو مخزون | المدير المالي | المدير العام | مجلس الإدارة | مجلس الإدارة |
| مورد جديد أو تغيير حسابه المصرفي | المشتريات + تحقق مستقل من الحسابات | | | |
| تعيين موظف أو زيادة راتب | الموارد البشرية + المدير المالي (موازنة) + المدير العام | | | |

**قواعد:**
- الحد يُقاس على **قيمة المعاملة الكاملة**، مو على الفاتورة الواحدة. تجزئة المشتريات للبقاء تحت الحد مخالفة، و`validate_costs.py --approval-limit` يكشفها.
- لا أحد يوافق على مصروف يخصه شخصياً (سفره، سيارته، راتبه).
- الصلاحية تفويض مكتوب، ويُراجع سنوياً وعند تغيّر الأشخاص.

## 4. النقد والمصارف

- **السلفة المستديمة (Imprest):** سقف ثابت، والتعويض بمستندات فقط. جرد مفاجئ شهرياً من شخص غير أمين الصندوق.
- **النقد الكبير:** التعامل النقدي شائع بالعراق، لكن كل مبلغ نقدي كبير خطر احتيال وخطر غسل أموال. حدد سقفاً للدفع النقدي، وفوقه تحويل مصرفي فقط.
- **المطابقة المصرفية:** شهرياً لكل حساب، خلال 5 أيام عمل، ويوقّعها المراجع. البنود المعلقة أكثر من 60 يوماً تُحقق.
- **صلاحيات المصارف الإلكترونية:** من يُدخل الحوالة غير من يعتمدها. الرموز (tokens) لا تُشارك.
- **حسابات الدولار:** طابق الرصيد بالدولار وبالدينار، وأعد تقييمه بسعر الإقفال (IAS 21).

## 5. الإغلاق الشهري

| اليوم | المهمة |
|---|---|
| قبل النهاية بيومين | تذكير الأقسام بالمستندات المعلقة، وقطع المشتريات والمبيعات |
| اليوم 1 | إقفال المخزون والاستلامات، وتسجيل الرواتب والضمان والضريبة المستقطعة |
| اليوم 2 | الاستحقاقات (خدمات مستلمة بدون فواتير)، والمدفوعات المقدمة، والاندثار |
| اليوم 3 | المطابقات المصرفية، وإعادة تقييم العملات، ومطابقة حسابات الأطراف ذات العلاقة |
| اليوم 4 | مطابقة الذمم المدينة والدائنة مع الأستاذ المساعد، ومخصص الخسائر الائتمانية، وتحليل الأعمار |
| اليوم 5 | ميزان المراجعة، والمراجعة التحليلية (كل بند تغيّر أكثر من 10% بلا تفسير يُحقق) |
| الأيام 6 إلى 8 | التقارير الإدارية، وتقرير التكاليف، والانحرافات وتفسيرها |
| الأيام 9 إلى 10 | مراجعة المدير المالي واعتماده، ثم التوزيع، ثم **قفل الفترة بالنظام** |

**مؤشر الجودة:** عدد قيود التسوية بعد الإقفال. إذا تكررت كل شهر، فالمشكلة بالعملية مو بالأشخاص.

## 6. مؤشرات الاحتيال وكيف تفحصها

| المؤشر | الفحص |
|---|---|
| مورد وهمي | مورد بدون سجل تجاري أو عنوان، أو حسابه المصرفي يطابق حساب موظف، أو تعامل نقدي فقط |
| تجزئة المشتريات | عدة فواتير لنفس المورد وبنفس الفترة، كل وحدة تحت حد الموافقة (`--approval-limit`) |
| فواتير مكررة | نفس المورد ورقم الفاتورة والمبلغ (يفحصها `validate_costs.py` تلقائياً) |
| مبالغ مدوّرة | فواتير خدمات كبيرة بمبالغ مدوّرة بدون تفصيل |
| قيود خارج الدوام | قيود بأيام العطل أو بالليل من مستخدمين غير معتادين |
| تغيير الحساب المصرفي للمورد | ثم دفعة كبيرة مباشرة بعده |
| موظف ما ياخذ إجازة | ويرفض أن أحداً يغطي شغله |
| أسعار أعلى من السوق | مع نفس المورد دائماً وبدون عروض منافسة |
| مخزون ينقص | فروقات جرد متكررة بنفس المواد |
| رواتب لأشخاص غير موجودين | قارن كشف الرواتب مع الحضور والهويات وأرقام الحسابات المكررة |

**إذا لكيت مؤشراً:** وثّق، ولا تواجه الشخص قبل تأمين الأدلة، وبلّغ حسب سياسة الشركة (المدير العام أو لجنة التدقيق). المؤشر يعني احتمالاً، مو إدانة.

## 7. الجاهزية للتدقيق (قائمة الطلبات المعتادة PBC)

ميزان المراجعة النهائي، والقوائم المالية ومسوداتها، وكشوف ومطابقات كل الحسابات المصرفية، وتأييدات الأرصدة، وأعمار الذمم المدينة والدائنة، وجرد المخزون وتقييمه، وسجل الأصول الثابتة وجدول الاندثار، والعقود الرئيسية، ومحاضر مجلس الإدارة والهيئة العامة، والملف الضريبي ووصولات التوريد، وكشف الضمان، وكشف الأطراف ذات العلاقة، والقضايا والالتزامات المحتملة، والأحداث اللاحقة (مثل قرار سعر الصرف 2026-10-07).

**قاعدة:** إذا المدقق طلب شيئاً مرتين، فالمشكلة عندنا. جهّز الملف قبل وصوله.

## 8. الحوكمة ولجنة التدقيق

- المدير المالي يرفع للجنة التدقيق أو مجلس الإدارة: الأداء مقابل الموازنة، والسيولة، والمخاطر الرئيسية، ونتائج التدقيق وحالة معالجتها، ومعاملات الأطراف ذات العلاقة.
- خطاب الإدارة من المدقق يُتابع بجدول: الملاحظة، والإجراء، والمسؤول، والموعد، والحالة.
- **الاستقلالية:** المدير المالي يكدر يوصل للجنة التدقيق مباشرة إذا تعرض لضغط لتغيير الأرقام.
